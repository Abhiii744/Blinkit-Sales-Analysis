
# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing Blinkit's sales data using Microsoft Power BI. The dashboard provides an interactive view of sales performance, product categories, outlet-level insights, and key business metrics to support data-driven decision-making.

## Objectives
- Analyze overall sales performance.
- Understand product and category-wise sales trends.
- Evaluate outlet performance.
- Identify key business insights through interactive visualizations.
- Present important KPIs in an easy-to-understand dashboard.

## Tools & Technologies
- **Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and business metrics.
- **Data Visualization** – Charts, KPI cards, slicers, and interactive reports.

## Dashboard Features
- KPI cards for key performance indicators.
- Sales analysis using interactive charts.
- Product and category-level analysis.
- Outlet performance analysis.
- Interactive filters and slicers.
- Visual representation of business trends.

## Key Learnings
- Data cleaning and transformation.
- Building interactive dashboards.
- Creating meaningful visualizations.
- Understanding business KPIs.
- Translating raw data into actionable insights.

## Project File
`blinkit.pbix` – Power BI dashboard file.

## How to View the Project
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard using available filters and visualizations.
